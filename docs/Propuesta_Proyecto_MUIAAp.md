| Área/s temáticas principales | ETL, Data Engineering, Machine Learning, Inteligencia Artificial. |
| Breve descripción del proyecto/Esquema | Este proyecto nace de la necesidad de optimizar la estrategia de gestión de datos y optimización de recursos sanitarios de la compañía, ya que la actual no cumple con los KPIs mínimos establecidos. La compañía basa todos sus trabajos sobre el sector farmacéutico y de salud en España, enfocados en el catálogo y las fichas técnicas del CIMA y del Ministerio de Sanidad. Los principales requisitos funcionales sobre los que se sustenta el proyecto son: i. Se requiere tener como fuentes de origen la API {REST} CIMA, Web Scraping CIMA y los datos del Ministerio de Sanidad en base a la enfermedad propuesta a cada grupo. ii. Se dispondrá de una base de datos MySQL para identificar las compañías farmacéuticas, los códigos nacionales (CN), CIK u otra información relevante sobre ellas (Tablas CIMA, Fichas y SNS). iii. Se requiere hacer uso de ETLs para tener la información de los medicamentos/compañías para posteriormente ser usados como inputs para el modelo. iv. Se requiere realizar un modelo de machine learning (clasificador para detección automática de criticidad/tipo) el cual en mayor o menor medida pueda ser explicado a cada uno de los departamentos. v. Se requiere documentar de manera detallada y justificada por qué se ha hecho uso de las tecnologías. vi. Enfermedades: cáncer, diabetes, hipertensión, asma, epilepsia, migraña, artritis reumatoide, psoriasis, esquizofrenia. |
